# Enemy Survivor

Juego 2D de supervivencia desarrollado en Unity y C#.

## 🎮 Características

- Combate cuerpo a cuerpo
- Ataques hacia izquierda y derecha
- Ataque aéreo hacia abajo
- Knockback de enemigos
- Sistema de vida del jugador y enemigos
- Barras de vida
- Oleadas progresivas
- Contador de enemigos derrotados
- Sistema de Game Over
- Reinicio de partida
- Menú principal
- Música de fondo

## 🛠️ Tecnologías

- Unity
- C#
- Unity Input System
- TextMeshPro
- Universal Render Pipeline

## 🎯 Objetivo

Sobrevivir a la mayor cantidad posible de oleadas de enemigos mientras aumenta la dificultad.

## 📌 Estado del proyecto

Proyecto jugable y con build funcional.
