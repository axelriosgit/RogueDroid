# Enemy Survivor

Juego 2D de supervivencia desarrollado con **Unity y C#**.

## 🎮 Características

* ⚔️ Combate cuerpo a cuerpo
* ↔️ Ataques hacia izquierda y derecha
* ⬇️ Ataque aéreo hacia abajo
* 💨 Knockback de enemigos
* ❤️ Sistema de vida del jugador y enemigos
* 📊 Barras de vida
* 👾 Oleadas progresivas
* 🎯 Contador de enemigos derrotados
* 💀 Sistema de Game Over y puntuación final
* 🔄 Reinicio de partida
* 🏠 Menú principal
* 🎵 Música de fondo

## 🎮 Controles

| Acción  | Tecla             |
| ------- | ----------------- |
| Moverse | `A / D` o `← / →` |
| Saltar  | `Space`           |
| Atacar  | `F`               |

## 🛠️ Tecnologías

* **Unity**
* **C#**
* **Unity Input System**
* **TextMeshPro**
* **Universal Render Pipeline**
* **Git / GitHub**

## 🎯 Objetivo

Sobrevivir a la mayor cantidad posible de oleadas de enemigos mientras la dificultad aumenta progresivamente.
